## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 + Rule 3 — Bug / Blocking] Fixed coordinate-capture API: `cmd.iterate` → `cmd.iterate_state`**
- **Found during:** Task 2 (writing + running `tools/wt_align_smoke.py`, Stage 4 coordinate capture)
- **Issue:** The plan prescribed `cmd.iterate("wt and name CA", "before.append((x, y, z))", space=...)` for capturing WT coordinates before/after the superposition. But `cmd.iterate` exposes only `name`/`chain`/`resi`/`resn` (and other non-spatial atom attributes) — it does NOT expose coordinates. Calling it with `x, y, z` in the expression raises `NameError('x/y/z only available in iterate_state and alter_state')`. Coordinates live only in the `iterate_state`/`alter_state` namespace. This blocked the smoke's before/after coordinate-comparison checks (Stages 4 + 5).
- **Fix:** Changed all 4 coordinate-capture calls in the smoke from `cmd.iterate(sel, "...x, y, z...", space=...)` to `cmd.iterate_state(1, sel, "...x, y, z...", space=...)` (state 1 = the first and only state), with the `# src: tmp/pymol-src/modules/pymol/editing.py:1578 cmd.iterate_state` citation verified against `tmp/pymol-src/modules/pymol/editing.py`. Added explanatory NOTE comments (lines 139-140, 163-166, 192-193) documenting the `iterate` vs `iterate_state` distinction for future smokes.
- **Files modified:** `tools/wt_align_smoke.py` (coordinate-capture mechanics only)
- **Verification:** the smoke runs headlessly with `SMOKE_RESULT: PASS`; the `super_moved_mobile` (x: 8.85→1.11) and `scoped_super_moved_whole_wt` (x: 6.11→1.46) checks now pass (they require the before/after coordinate capture the fix enables).
- **Committed in:** `c5ba316` (Task 2 commit)
- **Impact on the convention:** NONE. This changes the smoke's coordinate-capture API only; it does NOT touch the convention spec, the post-conditions, or the §6 molops dispatch pseudocode (which does not capture coordinates). The convention's `cmd.super`/`cmd.align` mechanism, argument order, and `transform=1` whole-object behavior are unaffected.
