## Decisions Made
- **Trailing-newline contract:** `dumps` returns WITHOUT the trailing newline; the file write appends it (the plan's recommended form; pinned by tests and consistent with the oracle).
- **RawFloat semantics:** strict token wrapper (not a float subclass) with token-based `__eq__`/`__hash__` — the literal IS the identity; plain Python floats (editor-side new values) emit `repr(float)` shortest-round-trip form.
- **Vector table = 11 entries:** the plan's 9 mandated categories plus 2 boundary pins — `dict_fits_exactly_at_width` (compact == 175 renders inline; ≤ inclusive) and `propagation_child_list_too_long` (a dict whose compact form fits ≤ 175 but whose child scalar list exceeds SW at its own depth must render multiline). Both are load-bearing rule-5/6 semantics verified against the real files (cast.json's longest entry lands at exactly 175).
- **Force-flag precision:** the edits exception applies to the direct elements of the array under `"edits"` only; nested arrays under an edits element render by the normal rules (`ser_keyed` recomputes per key) — exactly mirrorable in JS.
- **Measured boundaries recorded for the JS port:** cast entries compact 137–171 at indent 4 (max total exactly 175); manifest `files` compact 121 (total 123 > 110 → multiline); shuffle cond choice total 170 ≤ 175 → inline; without the edits exception 10/13 real edit entries would wrongly inline (fits_dict@8 True).
