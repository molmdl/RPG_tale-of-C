## Decisions Made
See `key-decisions` in the frontmatter; the load-bearing ones:
- **16-op shared vocabulary** (superset of Code Example 5's 13): the molops extras are dispatched ops — KNOWN to the parser, policed by the zero-restore guard; genuinely unknown ops (beyond molops itself) take the warn-but-accept path. Both behaviors were runtime-proven (frobnicate kept + warned; protonate guard-confirmed).
- **Guard messages cite their owning tests** (reachability :781-798 / :800-843 / :391-414 + the 07-17 invariant) so a confirmed-anyway violation points the editor user straight at the gate that will judge the saved file.
- **The hero-highlight guard includes the hero_atom load index** — deleting/moving the load breaks the sequence just as editing a highlight op does; the guarded index set is computed with the test's own ordered-subsequence walk (exact, recomputed from live data, so it self-heals if the data legitimately changes shape).
- **Retype replaces the op dict with the new op's skeleton** — a changed op identity invalidates the old args; keeping them would emit nonsense (e.g. edit_type on a zoom). Undo restores the previous dict in one step.
