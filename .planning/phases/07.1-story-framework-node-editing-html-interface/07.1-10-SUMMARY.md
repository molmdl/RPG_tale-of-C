## Decisions Made
See `key-decisions` in the frontmatter; the load-bearing ones:
- **Global visited set over path-only guard**: "already shown" only means something if the node was rendered ANYWHERE; it also makes the rendered node set identical to the BFS reachable set — the agreement property is structural, not incidental. Diamonds (A→B, A→C→B) render B once + one ↩ marker, keeping the full-story view compact and gate-faithful.
- **The walk is a named test contract**: isolating `traceWalk` lets the battery pin token absence in the body (the precise instrument the plan asked for) instead of fragile "weight appears after the walk" positional greps.
- **House-style double quotes** for the view registration (the plan's `'trace'` is quoting style, not a contract; the test regex accepts either).
- **Model-built copy text**: scraping the DOM would lose collapsed branches (display:none subtrees still exist in the model); building from the model guarantees copy == full story regardless of expand state.
