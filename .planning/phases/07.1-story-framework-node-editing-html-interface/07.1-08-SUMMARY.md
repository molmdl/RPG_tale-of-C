## Decisions Made
See frontmatter key-decisions. Highlights:
- **Severity contract mirrors the lint's exit contract:** errors → saveBlocked() true; notices never block (a run with only notices is the green form — the sanctioned residual IS a notice).
- **Normalized duplicate-signature detection** (plan-cited edit_router.py:122-149 semantics): two stored signatures colliding after normalization would collide at route() time; the editor flags them pre-save.
- **saveBlocked() re-validates on every call** — verdicts are never served stale, at trivial cost (~57 nodes).
- **Deferred the committed story_editor.html regeneration** (parallel-safety rule in the spawn prompt; 07.1-05 precedent): at commit time sibling assets were untracked/in-flight; regeneration to a temp path satisfies the verify step, and the next sibling regeneration bakes 20_validate.js into the committed artifact.
