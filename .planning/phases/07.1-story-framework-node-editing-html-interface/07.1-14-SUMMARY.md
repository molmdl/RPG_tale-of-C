## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing Critical] Registry dirty re-derivation for edits.json/cast.json across undo/redo**

- **Found during:** Task 1 (mutation discipline design)
- **Issue:** the two registries live at the bundle TOP LEVEL (not `bundle.files`), so the core's `recomputeDirty` — which compares `bundle.files` members only — could never re-derive their dirty state: an undo of a registry mutation would leave a stale dirty flag (false positive), and `80_save.markSaved`'s documented note ("no current mutator can dirty them") became false the moment this asset landed its mutators.
- **Fix:** wrapped `EDITOR.setBundle` (per-registry JSON baselines captured at load), `EDITOR.save.recomputeDirty` (registries re-derived against the baselines after the core's pass), and `EDITOR.save.markSaved` (baseline reset before the wrapped call so the confirmed file stays clean) — all from this asset, zero edits to other plans' files, story-file semantics untouched.
- **Files modified:** tools/story_editor_assets/50_editscast.js (the REGISTRY DIRTY HONESTY block)
- **Verification:** suite green; the wrapper interplay with the save layer's markSaved flow reasoned through both orderings (baseline-before-call keeps the confirmed file clean)
- **Committed in:** 91d1510 (Task 1 commit)

**2. [Rule 1 - Bug] editsEntryUpdate replaced the entry object (would drop unknown keys)**

- **Found during:** Task 1 (self-review against the B11 unknown-key preservation contract)
- **Issue:** the first draft replaced `list[index] = canonicalEntry`, silently dropping any future/unknown key on an existing entry, its signature dict, or its args — violating the editor's B11 ethos (unknown keys round-trip untouched).
- **Fix:** the update mutator now touches ONLY the named fields in place (signature.op/target/args.new_res + branch_node + claim_id), creating the signature/args dicts only when absent.
- **Files modified:** tools/story_editor_assets/50_editscast.js
- **Verification:** suite green; the B11 comment documents the contract
- **Committed in:** 91d1510 (Task 1 commit)
