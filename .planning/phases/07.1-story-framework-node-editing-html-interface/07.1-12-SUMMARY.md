## Decisions Made
See `key-decisions` in the frontmatter; the load-bearing ones:
- **Warning chips live in the claims panel, not on the graph**: the graph is 30_graph.js's file (parallel-asset ownership); the claims panel owns claim navigation, so per-node warning chips render in a warnings section (mirroring the lint's rules) with amber reverse-index chips in the detail.
- **Sanctioned residual as info, not alarm**: the grey annotated line states the citation gate's pinned 2-MISSING + 0-UNAPPROVED form; a red alarm is reserved for placeholder_misuse (the id anywhere else, or any other PLACEHOLDER*).
- **safeHttpUrl gate**: only `^https?://` URLs become anchors — cheap hardening against a tampered sources.json injecting `javascript:` hrefs (Rule-2-grade input validation).
- **`=== "pending"` equality kept for display counting** (the count line); the battery pins that only the strict `=== "approved"` predicate drives approval semantics and that NO `!= / !== "pending"` shortcut exists anywhere.
