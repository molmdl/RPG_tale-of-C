## Decisions Made
See `key-decisions` in the frontmatter; the load-bearing ones:
- **"VERBATIM" mechanism:** expected strings as ES5 double-quoted constants, decoded by the stdlib JSON parser for the WSL pin (multi-line string constants necessarily escape newlines; ES5 offers no raw-newline literal form, and the emitted-page ES5 discipline rules out template literals). The plan's own parenthetical ("embedded as JS string constants") describes exactly this embedding.
- **RawFloat is opt-in in JS** (no `parse_float` hook exists): editor code that must emit an exact float token wraps it explicitly; the limitation (JSON.parse cannot recover "2.40") is documented in the asset header per the plan, citing 07.1-02, with the mitigations (writable targets float-free; citations/sources read-only).
- **Fail-loud strictness:** undefined values and non-finite numbers throw instead of emitting corrupted output.
- **Canary owns its DOM node:** writes only to a self-created `#statusbar-serializer` span — no other plan's status spans are touched.
