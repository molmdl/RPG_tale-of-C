## Decisions Made
See `key-decisions` in the frontmatter; the load-bearing ones:
- **The title-field flag (for the human)**: nodes have NO title field. id-as-title is the mapping. If a literal editable title field is ever wanted, that is a schema change touching the engine + the 5.4 conformance battery and requires explicit sign-off — out of scope for the editor.
- **`EDITOR.ui.claimFocus` defined defensively by the earlier-sorting asset** (safe no-op default) so 07.1-12's claims panel can replace/extend it; the chips/✕ pairs are SIBLING elements so a remove-click can never also fire the focus hook.
- **is_ending "none" = key removal, never null** — implemented as a local `EDITOR.apply` action touching only that key; the battery's scoped `delete` review allowlists exactly this one line, proving no code path can delete unknown keys.
- **Validator errors bucketed per form section** (ISSUE_SECTION map: text/claims/tags/ending/other) read from `EDITOR._lastValidation` — the form is a read-only consumer of the 07.1-08 validator.
- **Strict-JSON literals for test parseability** (KNOWN_NODE_KEYS, like 30_graph.js's FILE_COL).
