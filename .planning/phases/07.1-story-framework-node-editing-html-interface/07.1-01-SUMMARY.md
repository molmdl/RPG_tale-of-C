## Decisions Made
See `key-decisions` in the frontmatter; the load-bearing ones:
- **Asset slot = comment-wrapped marker, replaced full-string** (`<!--/*__ASSETS__*/-->`): keeps the raw shell valid HTML and lets the marker expand to complete sibling `<script>` blocks; a hand-broken wrapper fails loud via the token-leak test.
- **`</script` -> `<\/script` hygiene on inlined assets**: prevents script breakout from a future asset's JS string/comment; semantics-preserving in JS strings and regexes.
- **Token order**: shell tokens (`__TITLE__`, `__GENERATED_AT__`, `__ASSET_MANIFEST__`) replaced BEFORE asset injection — asset JS is never token-scanned, so later assets may use braces freely.
- **Aux-file gate strictness mirrors the viewer**: citations/sources/edits REQUIRED, cast OPTIONAL-degrade (warning printed).
- **Gate = exactly the plan's 5 classes; zero pinned counts** (57/21/15 detection belongs to 07.1-03 lint / 07.1-08 JS mirror / the suite).
