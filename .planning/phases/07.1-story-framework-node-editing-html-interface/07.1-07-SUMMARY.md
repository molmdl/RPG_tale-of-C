## Decisions Made
See `key-decisions` in the frontmatter; the load-bearing ones:
- **Block vs warn by writability**: story files + edits.json (the editor WRITES these) block on missing/malformed — a partial bundle of writable files could destroy data on save; citations/sources/cast (read-only/display) degrade with loud warnings, matching the plan's degrade list and the viewer's cast convention.
- **parseNoDupKeys as a depth-1 structural walk**: the plan's two sketches (reviver with a seen-set; regex on line starts) are respectively impossible (revivers run after JSON.parse already collapsed duplicates) and whitespace-fragile; the walk is regex-free, ~40 lines, and exact at the flat top level where both registries live — the nested-key approximation is documented in-source and pinned by the battery.
- **Draft survives a folder re-pick**: RESEARCH-UI step 4 says a re-pick triggers the fingerprint comparison "against this draft" — so when `draftActive`, the pick refreshes the baseline + warns instead of replacing the session (reload the page to start from the folder). The full UX remains 07.1-13's.
- **Probe watchdog (4 s)**: the plan forbids a dead "loading…" state; a hung probe would be exactly that, so the picker self-reveals if the probe hasn't settled — belt-and-suspenders on top of the rejection path.
