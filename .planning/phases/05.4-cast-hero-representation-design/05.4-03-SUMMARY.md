## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Type 5 prochiral selection operator-precedence leak**
- **Found during:** Task 1 (writing the Type 5 rng-shuffle selection)
- **Issue:** The plan's `cmd.select("prochiral_pair", "citrate and name C1 or name C2")` parses as `(citrate and name C1) or (name C2)` (OR binds looser than AND in PyMOL selection grammar), so the bare `name C2` matches the C2 atom of EVERY loaded object sharing `_smoke.pdb`'s atom names — by Type 5, `current` and `substrate` (both loaded from `_smoke.pdb`) also have a `C2`. The selection would resolve to 4 atoms (citrate's C1 + all objects' C2), failing the `count == 2` post-condition.
- **Fix:** Parenthesized + object-scoped the selection: `cmd.select("prochiral_pair", "citrate and (name C1 or name C2)")` — resolves to exactly citrate's C1 + C2 = 2 atoms.
- **Files modified:** tools/scene_template_smoke.py
- **Verification:** `t5_prochiral_pair_count_2 prochiral=2` PASS (would have been 4 with the plan's literal expression).
- **Committed in:** eb4db34 (Task 1 commit)

**2. [Rule 1 - Bug] Stage 7 BEFORE state clobbered by Type 3b reset**
- **Found during:** Task 1 (writing the Stage 7 5.3 composition)
- **Issue:** The plan's Stage 7 BEFORE re-asserts the Type 3 `enzyme` mutant red spheres as "already applied in Type 3 — re-assert here." But Type 3b (the structural variant, which reuses the same `enzyme` object) does `cmd.hide("everything", "enzyme")`, which turns OFF the mutant spheres. By Stage 7 the BEFORE state is gone, so the bare re-assertion `count_atoms("enzyme and resi 1 and rep spheres") > 0` would FAIL (spheres=0).
- **Fix:** Re-apply the BEFORE (disease) state in Stage 7 before asserting it: `cmd.show("spheres", "enzyme and resi 1")` + `cmd.color("red", "enzyme and resi 1")`, with a comment explaining Type 3b reset the enzyme so the BEFORE is re-established to demonstrate the 5.4 BEFORE the 5.3 AFTER restores.
- **Files modified:** tools/scene_template_smoke.py
- **Verification:** `comp_before_mutant_red_spheres spheres=10 color='red'` PASS.
- **Committed in:** eb4db34 (Task 1 commit)

**3. [Rule 1 - Bug] create citation line number accuracy**
