- objects: `cmd.get_names("objects")` (querying.py:1148), filtered to molecule-type via `cmd.get_type(name)` (querying.py:1199); sorted alphabetically.
- reps per object: `cmd.count_atoms("<obj> and rep sticks")`, `... rep cartoon`, `... rep spheres` (querying.py:1412) > 0 probes.
- colors: `cmd.iterate(obj, "stored_lst.append(color)")` (editing.py:1490) — if all atoms share one index: named-palette match first via `cmd.get_color_index(p)` for p in [hero_cyan, gray, green, magenta, orange] (querying.py:851; compare indices); else `cmd.get_color_tuple(idx)` (querying.py:825) -> emit set_color+color pair. Mixed colors -> NOT CAPTURED comment.
- labels: `cmd.iterate(obj, "stored_lst.append(label)")` — non-empty uniform label -> label op with bare-string text (dispatch wraps as quoted expr per molops.py:164-170); mixed/empty -> skip or NOT CAPTURED.
- named selections: `cmd.get_names("selections")`; expression recovery attempted via `cmd.get_type(name)` (querying.py:1199 — verify empirically what it returns for a selection; if recoverable emit select_focus(name, expr), else `# NOT CAPTURED: named selection "<name>"`). Do NOT use `cmd.get("sel_state")` — use `cmd.get_selection_state` (querying.py:1512) only to note the selection's state in a comment.
- camera: `cmd.get_view()` (viewing.py:605) -> one `{"op":"set_view","args":{"view":[18 floats]}}` entry; print WARNING line (stdout, not JSON) that set_view dispatch lands in Phase 10 — molops.py frozen in Phase 7.
