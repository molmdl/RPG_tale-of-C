## Decisions Made

### The 3 CRITICAL/HIGH Disease-Mutant Decisions (CONFIRMED AS DEFAULTS)

The user approved the human review without overriding any of the 3 pre-flagged CRITICAL/HIGH decisions. Per the checkpoint contract, "approve without override" = all flagged defaults are CONFIRMED.

**1. IDH3A vs IDH1 (`tca.isocitrate_dh`): IDH3A M204I DEFAULT CONFIRMED.**
- **Skeleton default:** IDH3A M204I (DIS-IDH3A-01-cand) — the biochemically correct NAD+-dependent mitochondrial TCA enzyme (PDB 5GRF candidate).
- **Alternative (NOT adopted):** IDH1 R132H (DIS-IDH1-01-cand) — a real cancer-mutant (glioma OMIM 137800, real mutant PDB 3INM), narratively powerful but NOT the TCA enzyme (cytosolic NADP+-dependent isoform). Remains documented in the research doc as the flagged alternative for Phase 7 reconsideration if a stronger narrative is desired.
- **Rationale:** Scientific correctness wins over narrative power at the skeleton level. IDH3A is the TCA enzyme; IDH1 is not. Phase 7 may revisit if the narrative warrants.

**2. pyr.pdh cast PDB: 6CFO (WT, 2.70 Å) CAST CONFIRMED.**
- **Skeleton default:** 6CFO (wild-type, 2.70 Å, Whitley 2018 PubMed:29970614) — the same paper's V138M mutant is 6CER.
- **Mutant-reveal approach: DEFERRED TO PHASE 7.** The user did not specify (a) apply-edit (load 6CFO -> cmd.alter resi 138 -> diseased state, approximate geometry) vs (b) load-mutant-PDB (fetch 6CER V138M directly, real geometry, scientifically stronger per spec.md item 4). The skeleton keeps 6CFO as the cast; Phase 7 decides the mutant-reveal mechanism.
- **Alternative (NOT adopted):** 1NI4 (WT, 1.95 Å, partial) — remains documented as an alternative but is NOT adopted.
- **Rationale:** 6CFO is the WT cast with the matching mutant PDB (6CER) from the same paper — the strongest cast/mutant pair. The mutant-reveal approach is a Phase 7 content/on_enter decision, not a skeleton-structure decision.

**3. tca.citrate_synthase reframe: edit:structural REFRAME KEPT.**
- **Skeleton default:** The skeleton keeps the `edit:enzyme` tag + adds `edit:structural` (structural-exploration, NO disease mutant; the restoration narrative does NOT apply at CS — the player explores the citrate-synthase active site structure without a disease-mutant to "restore").
- **Alternative (NOT adopted):** Remove the `edit:enzyme` tag entirely.
- **Rationale:** Keeping edit:enzyme + edit:structural preserves the enzyme_id binding (so the EditRouter can route CS edits) while the edit:structural tag documents the structural-exploration exception. Removing edit:enzyme would break the EditRouter binding.
