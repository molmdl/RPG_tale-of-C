## Decisions Made

- **Aconitase PDB: TBD_ACONITASE placeholder (no fabrication).** Verified via UniProt REST API (`https://rest.uniprot.org/uniprotkb/Q99798.json`) that human mitochondrial ACO2 (UniProt Q99798) has ZERO PDB cross-references. The closest mammalian TCA-cycle aconitase structures are bovine (1ACO at 2.05 A — the classic Ogston-hypothesis teaching structure; 1AMI, 1AMJ, 8ACN, 1C96, 1C97, 1NIS, 1NIT) and porcine (7ACN, 5ACN, 6ACN, 1B0J, 1B0K, 1B0M). Per the no-fabrication rule, used `pdb:TBD_ACONITASE` as the load target and documented the bovine 1ACO candidate in `tca.aconitase.text_teaching` for Phase 7 human review. The molops load op will fail at runtime (PyMOL cannot fetch TBD_ACONITASE) — intended loud-fail behavior forcing Phase 7 resolution.
- **All new PDB loads use PLACEHOLDER_PHASE7* claim_ids; NONE added to citations.json/sources.json.** The 6 candidate PDB IDs (7FS3, 2OZL, 5W8J, 5GRF, 1OCC, TBD_ACONITASE) are a separate Phase 7 approval batch. The citation gate is NOT run on the skeleton during Phase 5.1.
- **RNG shuffle stays the SOLE stochastic node.** The 5 new TCA enzyme nodes are DOWNSTREAM of the shuffle (they embody its outcome, not new RNG). The cycle-trap mechanism (`visits.get('tca.shuffle', 0) > 5`) is preserved. `tca.malate_dh` has 2 choices (loop to shuffle OR forward to divert_to_good) but is a forced progression, not a tier-determining branch — SC5 class "neither".
- **`tca.malate_dh` SC5 class = "neither" (not MC-choice).** It has 2 choices but both keep the carbon in the TCA-or-exit flow (loop = cycle turns again, forward = exit to cataplerotic branch). Neither choice determines the ending tier (the tier was already determined by the shuffle + the prior loop-vs-forward choices). Per the task spec: "malate_dh has 2 choices — loop vs forward — but it's a forced progression not a tier-determining branch, so SC5 'neither'".
- **Edit-allowed nodes UNCHANGED (5 + tca.shuffle).** The expansion added NO new edit-allowed nodes. The 9 new nodes are all "neither" (forced-advance narrative or PDB-load nodes, not edit-allowed). PFK stays the sole glycolysis edit-allowed node.
