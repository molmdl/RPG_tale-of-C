## Decisions Made
- **Manifest created in Wave 2 (this plan), not in the parallel Wave 1 authoring plans.** The manifest lists all 7 skeleton files; authoring it before all files exist would create manifest-coordination races between the 3 parallel Wave 1 plans (01/02/03). Wave 2 runs after Wave 1 is complete, so the manifest is authoritative from creation. This is the plan's stated rationale and was honored exactly.
- **The SC2 GREEN test pins the EXACT ending distribution (11 = 1T+3G+2N+5B) and all 4 tiers reachable** — not just `is_ok`. This makes the user-confirmed asymmetric ending distribution (PROJECT.md row 107) a machine-checked invariant: a future edit that adds/drops an ending without updating the assertion fails loud. The test also asserts exactly 11 ending nodes (not just "all reachable"), catching both orphaned endings AND distribution drift.
- **The SC2 RED variant 1 orphans the REAL True ending (end.true)** by rebuilding `etc.atp_synthase` (its sole inbound edge) with a goto to `end.normal.co2`. This is the research's recommended RED: it tests a real structural break on the actual climax path (the soul-jump arc's terminal edge), not a synthetic extra node. The variant is built in-test on a `dict(g.all_nodes())` copy via `Node.from_dict` — the real skeleton is never modified.
- **Confirmed (by reading validate.py) the reachability checker walks `choice.goto` edges ONLY** — it does NOT traverse `on_enter_divert`. This means cond-gated edges (pyr.branch aerobic/anaerobic split; tca.shuffle cycle-trap → bad.cycle_trap_host_death) ARE traversed by the BFS regardless of cond, so both subtrees are structurally reachable. The anaerobic guard (`cond: flags.host_o2_low`) is a RUNTIME cond concern, not a structural one — correctly reflected in the GREEN test's docstring.
