- **SC1 taxonomy = derived + tags (zero schema change):** the 5 node types are a DERIVED SET computed from existing Node fields + a tags entry for edit-allowed. - **SC5 class = gameplay design decision (not mechanical derivation):** MC-choice = real branching nodes (≥2 tier-determining choices OR RNG-shuffle OR placeholder stub); both = edit-allowed + choices; neither = endings + single-Continue forced-advance nodes. Count: MC-choice=6, both=6, neither=22.
- **edit.prompt classified as MC-choice (placeholder stub):** its 3 choices are structural BFS paths, not player-facing; at runtime the EditRouter routes directly. Classified as MC-choice per the plan's design decision.
- **tca.co2_turn1/turn2 classified as neither (progression, not tier-determining):** the loop-vs-forward choice is a TCA-cycle progression decision, not a tier-determining branch (the real tier-determining branch is tca.divert_to_good downstream). The plan's count (MC-choice=6) reflects this.
