**`c14/engine.py`** — module docstring: "GameEngine: the turn loop. Wires StoryInterpreter + GameState + RngEngine. Emits MolAction lists to an injected sink (never cmd.* — testability boundary). Save/load syncs RNG state and replays on_enter to reconstruct the scene (Pattern 6). Pure-Python, stdlib only."

`class TurnResult(object)` — plain class: `__init__(self, node, molactions, eligible_choices=None)`. `node` is the current Node, `molactions` the on_enter MolAction list emitted on entry, `eligible_choices` the list of Choices the player can pick from (None or [] at an ending). `__repr__`.

`class GameEngine(object)`:
- `__init__(self, graph, molaction_sink=None)` — store `self.graph = graph` (a StoryGraph), `self.interpreter = StoryInterpreter()`, `self.molaction_sink = molaction_sink` (a callable taking a MolAction list, or None), `self.state = None`, `self.rng = None`.
- `start(self, character="glucose", seed=None)` — begin a new game:
  1. `self.rng = RngEngine(seed)` (seed=None → random mode; seed=int → fixed/demo mode).
  2. `start_id = self.graph.start_node()`; `self.state = GameState.new_game(character, self.rng.seed, start_id)`.
  3. `return self._enter(start_id)` (enter the start node, emitting its on_enter).
- `choose(self, index=0)` — make a choice on the current node:
  1. `node = self.graph.get_node(self.state.current_node)`.
  2. `pick = self.interpreter.pick_choice(node, self.state, self.rng)`.
  3. If `pick` is a list (non-weighted eligible choices): `choice = pick[index]` (player selects by index; guard index bounds → raise IndexError if out of range, or clamp — prefer raising for clarity).
     If `pick` is a single Choice (all-weighted, RNG decided): `choice = pick` (index is ignored — the RNG picked).
  4. `self.interpreter.apply_effects(choice, self.state)`.
  5. `return self._enter(choice.goto)` (advance to the goto node).
- `_enter(self, node_id, record_visit=True)` — the core enter routine:
  1. `node = self.graph.get_node(node_id)`.
  2. `self.state.current_node = node_id`.
  3. `actions = self.interpreter.enter_node(node, self.state, self.rng, record_visit=record_visit)` (records visit unless `record_visit=False`, detects ending, returns on_enter MolAction list).
  4. Sync RNG state: `self.state.rng_state = self.rng.get_state()` (so a save at any point captures the exact PRNG position).
  5. Dispatch to sink: `if self.molaction_sink is not None and actions: self.molaction_sink(actions)`.
  6. Compute `eligible_choices`: if `node.is_ending is None`, the choices the player could pick next = `self.interpreter.pick_choice(node, self.state, self.rng)` BUT only if it returns a list (non-weighted); if it returns a single Choice (weighted), `eligible_choices` is None (the RNG will decide on `choose` — there's no player selection). To avoid drawing the RNG twice, compute eligible_choices as: `[c for c in node.choices if self.interpreter._cond(c.cond, self.state) and c.weight is None]` (the non-weighted eligible ones the player picks from) — or simply `node.choices` if you prefer to let the UI filter. **Decision: `eligible_choices = node.choices if node.is_ending is None else []`** (simplest — the UI/test can filter by condition/weight; the engine doesn't pre-draw the RNG for the presentation). Document this.
  7. Return `TurnResult(node, actions, eligible_choices)`.
- `save(self, path)` — `self.state.rng_state = self.rng.get_state()` (sync before save); `SaveStore.save(self.state, path)`.
- `load(self, path)` — restore a saved game:
  1. `self.state = SaveStore.load(path)`.
  2. `self.rng = RngEngine.from_state(self.state.seed, self.state.rng_state)` (rebuild the exact PRNG position).
  3. `return self._enter(self.state.current_node)` (re-enter the current node — this replays its on_enter MolActions to reconstruct the scene, per Pattern 6). NOTE: re-entering increments visit_counts again — DECISION: add a `replay=False` param to `enter_node` (or to `_enter`) that skips the `record_visit` increment on load-replay, so loading doesn't double-count visits. **Implement: `_enter(node_id, record_visit=True)`** — pass `record_visit=False` from `load()`. The interpreter's `enter_node` should accept an optional `record_visit=True` flag and skip the increment when False. (Update the interpreter call in `_enter` to pass it through.)
  4. Return the TurnResult (the re-entered node + replayed MolActions + eligible choices).
- Add `__repr__`.
