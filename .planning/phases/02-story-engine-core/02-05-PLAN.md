**`tests/test_integration.py`** — module docstring: "End-to-end integration test: proves the Phase 2 architecture in WSL. Full playthrough with mock MolAction sink (success criterion #1), RNG determinism (#2), save/load round-trip with on_enter replay (#3), reachability green/red (#4). Pure Python, no PyMOL."

`class TestEndToEndArchitecture(unittest.TestCase)`:

Helper `_story_dir(self)` — `return os.path.join(os.path.dirname(os.path.abspath(__file__)), '..', 'data', 'story')` (CWD-independent — Phase 1 invariant).

Helper `_play(self, seed, sink)` — `eng = GameEngine(StoryGraph.load(self._story_dir()), molaction_sink=sink.append); eng.start('glucose', seed); tr = eng.choose(0); return eng, tr` (plays start → weighted choice → ending).

**Success criterion #1 — full playthrough, no PyMOL:**
- `test_full_playthrough_reaches_ending` — `sink=[]; eng, tr = self._play(0, sink)`; assert `tr.node.is_ending in ('good','bad')`; `eng.state.finished` is truthy; `eng.state.ending_tier == tr.node.is_ending`.
- `test_playthrough_emits_molactions_to_mock_sink` — the sink collected MolActions at the start node (2: hide_all + load) AND at the ending node (1: hide_all); assert `len(sink) >= 3` and at least one `MolAction.op == 'hide_all'` and one `MolAction.op == 'load'`.
- `test_no_pymol_import_full_stack` — after `_play`, `assert 'pymol' not in sys.modules` (the entire stack — engine + interpreter + graph + rng + state + persist — never imported pymol; the testability boundary holds end-to-end).
- `test_no_pyqt_import_full_stack` — `assert 'PyQt5' not in sys.modules` (also no Qt).

**Success criterion #2 — RNG determinism:**
- `test_same_seed_same_ending` — play with seed 0 twice (`_play(0)` ×2); assert both runs reach the SAME ending tier. (Determinism: same seed → same outcome.)
- `test_same_seed_same_molaction_sequence` — play with seed 0 twice; assert the two sinks have equal MolAction sequences (same op/target/args in order). (The whole playthrough is reproducible, not just the ending.)
- `test_diff_seed_both_endings_appear` — play with seeds 0..30 (31 runs); collect the set of ending tiers reached; assert `set == {'good', 'bad'}` (both endings appear across seeds — different seed → different outcome; with 50/50 weights, 31 seeds robustly cover both). Use `collections.Counter` to count.
- `test_random_mode_reproducible_after_record` — `eng = GameEngine(...); eng.start('glucose', None)` (random mode); recorded_seed = `eng.state.seed`; save; `eng2.load(path)`; assert `eng2.state.seed == recorded_seed` AND a fresh `GameEngine.start('glucose', recorded_seed)` reaches the same ending as the random-mode run did. (A random-mode run is replayable from its recorded seed — classroom reproducibility.)

**Success criterion #3 — save/load round-trip:**
- `test_save_load_restores_identical_state` — `_play(0)` to an ending; save to temp path; load into a fresh engine; assert `eng2.state.to_dict() == eng.state.to_dict()` (every field incl. rng_state, current_node, visit_counts, ending_tier).
- `test_save_load_replays_on_enter` — after load, the fresh engine's sink collected the current (ending) node's on_enter MolActions (the scene is reconstructed by replay — Pattern 6). Assert `len(eng2_sink) >= 1`.
- `test_save_mid_playthrough_load_continues_same` — THIS is the strongest save/load proof: start (seed 42), but DON'T choose yet — save NOW (mid-playthrough, at intro.start, rng_state captured after the start-node draws). Load into a fresh engine. Now `eng2.choose(0)` and compare to a parallel run that did `eng.choose(0)` without saving. Assert both reach the SAME ending tier. (The save/load preserved the exact RNG position, so continuing from the save reaches the same outcome as never having saved.) 
  - Implementation: `eng1.start('glucose', 42); eng1.save(p)` (save before choose). `eng1.choose(0)` → ending1. `eng2.load(p); eng2.choose(0)` → ending2. assert ending1 == ending2. (Both engines had the same rng_state when `choose` drew, so same ending.)
- `test_save_load_no_double_visit` — start (visit_counts[start]=1), save, load → `eng2.state.visit_counts[start] == 1` (replay doesn't double-count — the `record_visit=False` on load).
- `test_save_file_is_human_readable_json` — save to temp path; read the file text; `json.loads(text)` succeeds; assert `'"current_node"'` and `'"seed"'` and `'"rng_state"'` are in the text (human-readable, diff-friendly — Decision D2).

**Success criterion #4 — reachability green/red:**
- `test_reachability_green_on_toy_graph` — `g = StoryGraph.load(self._story_dir()); nodes = g.all_nodes(); rep = check_reachability(nodes, g.start_node())`; assert `rep.is_ok` (both endings reachable from intro.start). Assert `set(rep.reachable_endings) == {'intro.ending_good', 'intro.ending_bad'}` and `rep.unreachable_endings == []`.
- `test_reachability_red_on_orphaned_variant` — construct an orphaned variant INLINE: take the real graph's nodes, ADD an orphaned ending node `"intro.ending_orphan"` (is_ending="bad", no choices, no incoming edge), run `check_reachability(orphanned_nodes, 'intro.start')`; assert `not rep.is_ok` and `"intro.ending_orphan" in rep.unreachable_endings`. (Build the orphaned nodes dict by copying `g.all_nodes()` and adding the orphan — use `dict(g.all_nodes())` then `orphaned["intro.ending_orphan"] = Node.from_dict({...})` or a raw dict — `check_reachability` accepts both.)
- `test_validate_graph_clean_on_toy_graph` — `validate_graph(g.all_nodes())` returns `[]` (no dangling diverts in the toy graph).

**Cross-cutting:**

So this test should either (a) create a temp registry with the toy story's claim_ids approved, or (b) assert exit 1 with the expected [MISSING] report. **Decision: create a temp registry with the 3 toy claim_ids approved** and assert exit 0 — this proves the refactored gate works on the multi-file directory end-to-end.) Use subprocess with `stdout=PIPE, stderr=PIPE` (NOT capture_output — 3.7+; Phase 1 pattern). Use `sys.executable`. Build the temp registry in `setUp`/inline with `tempfile`.
