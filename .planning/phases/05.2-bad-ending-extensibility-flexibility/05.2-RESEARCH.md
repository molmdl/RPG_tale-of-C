## Q3: Parametrized extensibility test structure (THE design decision)

**Decision:** Use `unittest.TestCase.subTest()` (available on 3.6.9 — verified `hasattr(tc,'subTest')==True`). **Generalize the existing `test_all_new_bad_endings_reachable_from_edit_prompt`** (rename + rewrite body) into a **dynamic `subTest` convention proof** that iterates `edit.prompt.choices` dynamically — auto-covering the 12 existing + the new `bad.denature_ph_change` + any future Phase 7 addition **without test edits**.

### Why generalize (replace), not add separate

- The existing test (L300-348) **hardcodes the 9 Plan-12 ids** in a `new_bad` list + uses a plain `for`/`assertIn` loop + slices `new_bad[:6]`/`new_bad[6:]` for the 1a/1b tag check. It would NOT cover `bad.denature_ph_change` (a 10th) without editing the hardcoded list.
- A dynamic `subTest` that discovers bad-ending targets from `edit.prompt.choices` is **strictly stronger**: it auto-covers the new node + future Phase 7 additions. Keeping both is redundant.
- The 05.1-14 precedent supports **renaming** an existing test method (`_43_nodes`→`_54_nodes`); generalizing + renaming this test is the same pattern.

### Why (a)+(b) over a "convention proof that mutates a copy"

Option (a)+(b) — assert on the REAL skeleton (with the new node added) — is cleaner than programmatically adding a bad ending to a COPY of the graph. The "mutate-a-copy" approach duplicates the addition logic in the test + tests a synthetic graph, not the real one. The convention proof is: **the real post-addition skeleton has all edit.prompt-reachable bad endings valid + reachability GREEN + invariants hold.**

### Concrete subTest skeleton (replaces the existing test body + renames the method)

```python
def test_all_edit_prompt_bad_endings_reachable_convention(self):
    """Bad-ending extensibility convention (Phase 5.2): every bad ending
    reachable from the edit.prompt structural stub is a valid bad ending
    with a correct edit:* tag, and the full-graph reachability stays GREEN.
    Parametrized via subTest over the stub's structural choices so future
    additions (Phase 7 content) auto-verify WITHOUT test edits. The 14
    edit-allowed + 0 single-Continue invariants are covered by the UNCHANGED
    test_14_edit_allowed_nodes + test_no_single_continue_choice (which still
    pass after the addition — see those tests)."""
    g = StoryGraph.load(self._story_dir)
    edit_prompt = g.get_node("edit.prompt")
    # The 3 structural tag categories the stub uses (1a unknown-pool / 1b
    # known-consequence / known-critical). Each structural choice to a bad.*
    # node carries exactly one.
    valid_edit_tags = ("edit:unknown", "edit:known", "edit:known_critical")
    bad_targets = []
    for c in edit_prompt.choices:
        if c.goto is None or not c.goto.startswith("bad."):
            continue  # the stub only points at bad endings
        with self.subTest(choice_goto=c.goto):
            # Convention 1: the structural choice points at a real bad ending.
            self.assertIn(c.goto, g.all_nodes(),
                          "structural choice target %r must exist" % c.goto)
            self.assertEqual(g.get_node(c.goto).is_ending, "bad",
                             "target %r must be is_ending=bad" % c.goto)
            # Convention 2: the choice carries a valid edit:* tag so Phase 7
            # can route deterministically (1a random / 1b deterministic / crit).
            ctags = c.tags or []
            self.assertTrue(
                any(t in valid_edit_tags for t in ctags),
                "choice to %r must carry one of %s; got %s"
                % (c.goto, valid_edit_tags, ctags))
            bad_targets.append(c.goto)
    # Shrinkage regression guard: the stub reaches >= the current count
    # (13 = 12 from 05.1-12 + bad.denature_ph_change). Phase 7 additions
    # (14+) auto-pass (>= 13); accidental removal (12) fails loudly.
    self.assertGreaterEqual(
        len(bad_targets), 13,
        "edit.prompt should reach >=13 bad endings after Phase 5.2; "
        "got %d: %s" % (len(bad_targets), sorted(bad_targets)))
    # Convention 3: adding a bad ending does NOT break reachability (GREEN).
    rep = check_reachability(g.all_nodes(), g.start_node())
    self.assertTrue(rep.is_ok,
                    "reachability stays GREEN after the bad-ending addition")
    self.assertEqual(rep.unreachable_endings, [],
                     "no unreachable endings after the bad-ending addition")
```

**Note on invariants:** the SC's "14 edit-allowed + 0 single-Continue invariants hold" is covered by the **existing unchanged** `test_14_edit_allowed_nodes` (L207) + `test_no_single_continue_choice` (L188) — they are NOT re-asserted in the new test (avoids duplication; the docstring cross-references them). The new bad ending is an ending node with `choices=[]` (not edit-allowed, not single-Continue), so those invariants are structurally unaffected.

**Suite size:** stays at **9 tests** (rename 1: `_54_nodes`→`_55_nodes`; generalize-and-rename 1: the bad-ending test). The 05.1-14 precedent grew 8→9 by adding; 5.2 stays at 9 by replacing.

- The skeleton carries **STRUCTURE only** (a node representing the pH-denaturation failure mode); the placeholder is the explicit "citation deferred to Phase 7" marker, not a claim.

**This does NOT violate the no-fabricated-science rule.** The planner must NOT invent a specific DOI/textbook-section in Phase 5.2 — the placeholder + TBD text is the entire Phase 5.2 scientific payload; the citation is Phase 7 (requires human approval per AGENTS.md).
