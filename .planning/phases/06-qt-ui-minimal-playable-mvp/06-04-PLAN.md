  <name>Task 1: Create c14/achievements.py — AchievementBoard + catalog + on_turn unlock logic</name>
  <files>c14/achievements.py</files>
  <action>
Create `c14/achievements.py` (pure-Python: `json`, `os`, `datetime` + `from c14.paths import user_data_path`; NO pymol/PyQt5). Implement the FROZEN-verbatim design from 06-RESEARCH-persistence-achievements.md Pattern 3 (lines 204-280):

- `ACHIEVEMENT_CATALOG_V1` — list of `(id, name, description)` tuples for the 6 v1 achievements: `first_game` ("First Steps", "Started your first playthrough"), `glucose_tried` ("Glucose", "Began a playthrough as glucose"), `true_ending` ("Soul Harvested", "Reached a True ending (electrons -> ATP via ETC)"), `bad_ending` ("Lost Connection", "Reached a Bad ending"), `good_ending` ("Retained", "Reached a Good ending (carbon body retained)"), `normal_ending` ("Released", "Reached a Normal ending (CO2 released)"). NOTE: only `glucose_tried` is defined for Phase 6 (glucose MVP); `fatty_acid_tried`/`alcohol_tried` are Phase 8 — `_unlock` no-ops on unknown ids (catalog lookup misses) so future expansion is safe (document this in a comment).
- `TIER_ACHIEVEMENT_ID` — dict mapping `{"true":"true_ending","good":"good_ending","normal":"normal_ending","bad":"bad_ending"}`.
- `AchievementBoard` class:
  - `__init__(self, path=None)` — `self.path = path or str(user_data_path("achievements.json"))`; `self.data = {"version":1,"characters_tried":[],"endings_found":[],"branches_discovered":[],"achievements_unlocked":[]}`; `self._load()`.
  - `_load(self)` — if `os.path.isfile(self.path)`: `json.load`; for each key in `self.data`: `self.data[k] = loaded.get(k, self.data[k])` (forward-compatible .get merge).
  - `_save(self)` — `os.makedirs(parent, exist_ok=True)`; `json.dump(self.data, fh, indent=2)`; `fh.write("\n")` (matches SaveStore's indent=2 + trailing-newline style, persist.py:38-65).
  - `_unlock(self, achievement_id)` — if already unlocked (any `a["id"] == achievement_id`), return; else look up `(aid, name, desc)` in `ACHIEVEMENT_CATALOG_V1`; if found, append `{"id":aid,"name":name,"description":desc,"date": datetime.datetime.utcnow().isoformat() + "Z"}`. If the id is NOT in the catalog (e.g. `fatty_acid_tried` in Phase 6), no-op (safe for future expansion).
  - `on_turn(self, turn_result, character, is_new_game=False)` — the controller calls this after each `engine.start`/`choose`/`apply_player_edit`. Logic (idempotent — dedupe by id):
    - `changed = False`
    - if `is_new_game`: `self._unlock("first_game")`; if `character and character not in self.data["characters_tried"]`: append + `changed=True`; `self._unlock(character + "_tried")` (e.g. `glucose_tried`).
    - `node = turn_result.node`; if `node.id not in self.data["branches_discovered"]`: append + `changed=True`.
    - if `node.is_ending is not None`: build `entry = {"node_id":node.id,"tier":node.is_ending,"character":character,"date":...}`; if `not any(e["node_id"]==node.id for e in self.data["endings_found"])`: append + `changed=True`; `self._unlock(TIER_ACHIEVEMENT_ID.get(node.is_ending))`.
    - if `changed or self.data["achievements_unlocked"]`: `self._save()` (the `_unlock` may have appended). Actually: save whenever `_unlock` appended OR `changed` — simplest: always call `self._save()` at the end if anything changed. Use a `changed` flag tracking all mutations including `_unlock` (have `_unlock` return bool, OR check len before/after).

AVOID: do NOT make it a leaderboard (no scores/ranks — ACH-01 explicit; 06-RESEARCH-persistence-achievements.md Anti-Pattern). do NOT import pymol/PyQt5 (gate-scanned — c14/ root). do NOT use `@dataclass` (3.6). do NOT cap `endings_found`/`branches_discovered` (cap deferred to content/UI phase — ACH-02; ship the open collections). do NOT couple to the engine (the engine stays pure-domain; the CONTROLLER calls `board.on_turn`, not the engine — 06-RESEARCH-persistence-achievements.md Open Question 6).
  </action>
