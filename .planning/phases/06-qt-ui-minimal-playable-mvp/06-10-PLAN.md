`BulkDownloadDialog(QtWidgets.QProgressDialog)`:
- `__init__(self, cmd, missing_codes, parent=None)`: `super().__init__("Downloading structures...", "Cancel (after current file)", 0, len(missing_codes), parent)`; `setWindowTitle("RPG: Tale of C — One-time Structure Download")`; `setWindowModality(QtCore.Qt.ApplicationModal)`. - `_on_cancel(self)`: `self._canceled = True` (the loop checks BETWEEN fetches, not mid-fetch — 06-RESEARCH-persistence-achievements.md Pitfall 7; the button label says "after current file" to set expectations).
- `run(self)`:
  ```python
  from .bulk_download import run_bulk_download
  def on_progress(i, total, pdb_id):
      self.setLabelText("Downloading {0} ({1} of {2})...".format(pdb_id, i + 1, total))
      self.setValue(i)
      QtWidgets.QApplication.processEvents()   # keep cancel button + label live
  def on_cancel_check():
      QtWidgets.QApplication.processEvents()
      return self._canceled
  result = run_bulk_download(self._cmd, self._missing, on_progress=on_progress, on_cancel_check=on_cancel_check)
  self.setValue(len(self._missing))
  return result
  ```
