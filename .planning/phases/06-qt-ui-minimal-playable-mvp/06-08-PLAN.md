- `__init__(self, parent=None)`: `QVBoxLayout`; `self._dramatic = QLabel()` with `setWordWrap(True)` + `setStyleSheet("font-size: 14pt;")` (prominent); `self._teaching = QLabel()` with `setWordWrap(True)` + `setStyleSheet("font-size: 10pt; color: gray;")` (dimmed); add both to layout. `ChoicePanel(QtWidgets.QWidget)`:
- `__init__(self, controller, parent=None)`: store the controller; `self._layout = QVBoxLayout(self)`; `self._buttons = []`.
- `render_turn(self, turn, controller)`: clear the existing buttons (`for b in self._buttons: b.deleteLater()`; `self._buttons = []`). Then:
  - Get the current node from `turn.node`.
  - If `node.is_ending is not None`: show a "Ending reached" label + a "[Start a new game]" button (calls controller.start_game via a re-open of the StartDialog — or just a disabled state). No choice buttons.
  - Else if `controller.is_mixed_weighted_node(node)` (the tca.shuffle case): render a "Spin the wheel" button (`clicked -> controller.choose(0)` — the RNG picks among the weighted) + for each NON-weighted eligible choice, a separate button:
    - For an `edit:offer` choice (tag `edit:offer`): button label = choice.label (e.g. "Try to edit aconitase"); `clicked -> controller.request_edit(controller._current_enzyme_id())` (06-06's request_edit stashes the enzyme_id from the current edit-allowed node's `edit:enzyme:<id>` tag + goto edit.prompt; the MainWindow's render_turn then detects `turn.node.id == "edit.prompt"` + opens the EditDialog with the stashed id — Warning 4 seam. Do NOT call take_choice for edit:offer — request_edit bundles the enzyme_id stash + the goto so render_turn has the id).
    - For a `cycle_trap` choice (or any cond-gated choice): only ENABLE the button if `controller._engine.choice_cond_met(choice)` is True (the cycle-trap appears after 6 visits); label = choice.label; `clicked -> controller.take_choice(choice)`.
    - Disable the non-weighted buttons whose cond is not met (grey out the cycle-trap until visits > 5).
  - Else (pure MC or pure weighted): for each eligible choice (the engine returns the raw node.choices; the controller/panel filters by cond via `controller._engine.choice_cond_met`), render a QPushButton with `choice.label`; `clicked -> controller.choose(index)` for non-weighted OR `controller.choose(0)` for pure-weighted (the RNG picks; show both weighted labels with a "(luck decides)" note). Disable choices whose cond is not met.
  - Use `lambda c=choice, i=index: controller.choose(i)` / `lambda c=choice: controller.take_choice(c)` to capture the choice/index in the signal (avoid the late-binding closure bug).
- `clear(self)`: remove all buttons.

Keep it simple per PROJECT.md (no rich-text markdown; plain text + maybe bold). Use `.format()` (3.6; no f-strings required).

AVOID: do NOT call cmd.* from the widgets (the controller + molops own molecular ops; the widgets only render + emit signals). do NOT re-implement cond eval (delegate to `controller._engine.choice_cond_met`). do NOT re-implement weighted-pick logic (the engine's choose handles it; the panel just calls controller.choose). do NOT put the OQ-6 QMessageBox inside the panel (the controller's prompt_fn handles it; the panel is dumb). do NOT use f-strings (3.6 — use .format()).
